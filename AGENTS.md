# Working rules

- Keep game images, extracted code/assets, firmware, saves, raw disassembly,
- Track original tools, independently written source, research notes, hashes,
- Treat addresses as specific to the exact ELF hash in docs/disc-report.json.
- Distinguish observations, hypotheses, and demonstrated behavior. Generated
- Never replace unknown game behavior with silent success just to advance boot.
- Preserve Downloads originals and record reproducible commands and tool revisions.
- Run `python3 -m unittest discover -s tests -v` after changing inspection tools.
- Keep repository docs current as evidence changes.
- Keep at most one native game/demo window open. Close a finished test window
